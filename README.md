# Eventify

Egy modern esemény kereső, létrehozó és kezelő portál Angular és Node.js alapokon, amely lehetővé teszi a felhasználók számára, hogy eseményeket tegyenek közzé és kezeljenek.

## Tartalomjegyzék  
- [Telepítés](#telepítés)  
- [Funkciók](#funkciók)  
- [Technológiák](#technológiák)  
- [Fejlesztők](#fejlesztők)  


## Funkciók  
✅ Felhasználói regisztráció és bejelentkezés  
✅ Hirdetés feladása, szerkesztése, törlése  
✅ Kategória szerinti szűrés és keresés  
✅ Automatikus hirdetés törlés 7 nap után  

## Technológiák  
- **Frontend:** Angular 17, Angular Material  
- **Backend:** Node.js, Express.js, ORM  
- **Adatbázis:** MySQL  
- **Autentikáció:** JWT  

## Telepítés  

### Backend  
1. **Klónozd a repót:**  
   ```bash
   git clone https://github.com/felhasznalo/classified-ads.git
   cd classified-ads/backend
   
2. **Telepítsd a függőségeket:**
    npm install

3. **Indítsd el a szervert:**
    npm start

### Frontend
1. **Menj a Public mappába:**
    cd ../Public
   
3. **Telepítsd a függőségeket:**
    npm install
   
4. **Indítsd el az Angular alkalmazást:**
     npm start
